Межмодульные связи

  • Профиль → Control → TUNUI редактирует настройки; consent и foreground service создают туннель, Rust передаёт TCP/DNS в upstream.
  • Physical network → Gateway → HostUI и service независимо обновляют gateway. Auto-mode записывает Host; ручной адрес не заменяется.
  • Active upstream → HTTPS probe → YouTubeПроверяется текущий proxy snapshot, не просто прямой интернет app UID. YouTube открывается только по нажатию.
  • Source SHA → CI → Signed release → InstallerBlocking software tests и actual APK checks предшествуют публикации. Android/user подтверждают установку.
  • LAN discovery → Catalog → Profile (план)Найденный endpoint становится кандидатом/профилем только после явного выбора; автоматического сканирования сейчас нет.

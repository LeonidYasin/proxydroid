# Обновление приложения и установка APK

## Пользовательский поток

**⋮ → Update app → Stable / Test → Check latest → Download APK**. После успешной проверки скачанного APK установщик Android вызывается автоматически, только пока Activity видима/resumed. Системное подтверждение остаётся обязательным — это не silent install.

Под полосой загрузки после завершения появляется полный фактический `File.absolutePath`, например `/data/user/0/org.proxydroid/cache/updates/proxydroid-v…apk`. Строка не обрезается и переносится; она фокусируема пультом и запускает повторную установку по нажатию / DPAD OK. Доступна и кнопка Install. Повторная скачка не нужна. Файл приватный: обычный файловый менеджер не может открыть этот raw path. Установщику передаётся защищённый `content://` FileProvider URI с временным read grant и ClipData. Это намеренное ограничение, не общая папка Downloads.

Если Android запрещает установку из ProxyDroid, открывается настройка разрешения для приложения (fallback — настройки безопасности ТВ). После разрешения и возврата установка возобновляется. Если установка отменена — APK остаётся, нажмите путь/Install снова. Закрытие диалога отменяет ожидающий запуск; скачивание/проверки не продолжаются как скрытая установка. Кэш может быть удалён Android, пользователем или переустановкой; после process death повторное восстановление каталога пока не обещается.

## Исправление 3.8.1

Ранее download завершался сохранением File, без автоматического перехода, а installer запускался из Application context + NEW_TASK только отдельной кнопкой. Это могло быть неочевидно на ТВ и зависеть от ограничений/OEM handler. Теперь запуск идёт из видимой Activity, сначала ACTION_INSTALL_PACKAGE, при отсутствии обработчика — ACTION_VIEW с MIME APK. Нет предположения о конкретном package name установщика. Конкретную причину сбоя на пользовательской приставке без logcat установить нельзя; изменения закрывают эти известные слабые места.

Перед каждой попыткой выполняется IO перепроверка cache bytes (size/SHA-256), реальных package/version/minSDK/JNI ABI и текущей подписи. Подменённый или удалённый файл не передаётся установщику. Скачивание только HTTPS GitHub с allow-list redirects и лимитами. Отладочные/unsigned APK не предлагаются; downgrade запрещён.

## Диагностика на приставке

1. Выберите Test для текущего RC. Дождитесь сообщения APK verified и полного пути.
2. Подтвердите разрешение неизвестного источника только для ProxyDroid.
3. При возврате ожидайте системный экран установки. Если не появился — выберите строку пути / Install; запишите текст ошибки.
4. Проверяйте обновление **release → release с тем же сертификатом**, без удаления приложения. С debug-подписи обновление невозможно.
5. Для поддержки приложите Android version, модель/прошивку, текущую/целевую версию, сообщение UI и очищенный logcat. Не публикуйте credentials/сырой полный лог.

Автотесты проверяют кликабельный/необрезанный путь, запрет действия в busy, intent MIME/content URI/read grant/ClipData и отсутствие NEW_TASK/file://. Они не доказывают запуск OEM installer, выдачу неизвестных источников или установку APK на реальной ТВ-приставке. Эти сценарии требуют device QA.

# Профили: сохранение, переименование и удаление

Следующий draft основан на тестовой 3.9.0. Он не меняет установленную 3.9.0 и не публикует релиз.

## Правила хранения

`ProfileStore` сохраняет совместимость с текущими SharedPreferences: выбранный `profile`, flat-поля текущей конфигурации, JSON по ID, `profile<ID>`, `profileValues` и `profileEntries`. Новая база/Room и миграция credentials не вводятся.

Каждое действие обновляет связанную конфигурацию одним `Editor.apply()`. Это атомарность preference-транзакции, а не обещание синхронного fsync: Android записывает apply на диск асинхронно. UI выполняет операции на main thread без отложенной IO-записи, которая могла бы перезаписать более новый выбор.

- Переименование обновляет JSON, flat name, отдельную label и список сразу.
- Создание сохраняет прежний профиль под прежним ID и создаёт чистый новый; пароли не копируются. LAN-выбор отдельно сохраняет пользовательскую app-routing policy.
- Выбор сохраняет последние flat-правки предыдущего профиля. Устаревший выбор уже удалённого ID игнорируется.
- Удаление убирает JSON, label и ID из обоих индексов. Следующий оставшийся профиль становится выбранным.
- При удалении последнего профиля создаётся чистый `Profile 1`: пустые Host/user/password/routing, выключенные auth/automation/auto-gateway, порт 10808. В UI остаётся одна пригодная для настройки запись.
- Legacy-индекс нормализуется: дубликаты и некорректные/неположительные ID отбрасываются, текущий валидный ID и его flat-настройки сохраняются. Пропущенный индекс не теряет уже настроенный текущий профиль. При максимальном Int-ID ищется свободный положительный ID без переполнения.

## Ограничения безопасности

Удаление профиля удаляет его credentials из текущего логического хранилища, но не гарантирует физическое стирание старых блоков флеш-памяти. Keystore-backed шифрование credentials — отдельный пункт roadmap.

Редактирование/выбор/удаление не изменяет снимок уже работающего VPN. Текущая сессия продолжает использовать применённый upstream до штатного останова/переподключения, в том числе если её профиль удалён. Это не команда очистить native-сессию. Для остановки используйте строку соединения или меню восстановления.

## Проверки

Unit: legacy bootstrap с credentials, rename/switch, полное удаление и reload, последний профиль, duplicate/invalid ID, overflow, stale selection, атомарное сохранение последних flat-правок.
Android: реальные SharedPreferences и MainViewModel; создание/переименование/переключение, удаление/reload, очистка последнего профиля, быстрые последовательные действия. Существующий LAN-тест также проверяет сохранение старого профиля и отсутствие переноса пароля.

Не заменяет проверку на Rombica и не подтверждает устранение зависания YouTube.
